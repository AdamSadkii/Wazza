# Wazza hardware

| Path | What |
|------|------|
| `kicad/` | KiCad 10 project (schematics + routed PCB) |
| `cad/Wand3.step` | Enclosure CAD (Onshape / Wand3 export) |
| `gerbers/` | Gerber + Excellon drill (+ `wazza_gerbers.zip`) |
| `wiring/` | Schematic PDF + PCB preview / routed renders |
| `WIRING.md` | Net / pin map |
| `ASSEMBLY.md` | Build and assembly steps |

Open `kicad/wazza.kicad_pro` in **KiCad 10**.

## Quick fab

Upload `gerbers/wazza_gerbers.zip` to JLCPCB / PCBWay (or similar).  
Board outline: **155 × 26 mm**, 2-layer.
